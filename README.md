Este projeto marca o início da minha jornada no desenvolvimento web. O Codificador de Palavras foi meu primeiro projeto prático usando DHTML (HTML, CSS e JavaScript). Foi uma experiência desafiadora e ao mesmo tempo emocionante, onde dei meus primeiros passos rumo ao desenvolvimento de sistemas. Esse projeto representa muito mais que apenas código — é a realização de um sonho, impulsionado por um propósito e guiado por um objetivo.

🚀 Sobre o Projeto
O Codificador de Palavras é uma aplicação simples de front-end que permite:

Codificar palavras, transformando-as em uma versão "criptografada".
Decodificar palavras, revertendo-as ao seu formato original.
Objetivos:
Colocar em prática os conceitos iniciais de HTML, CSS e JavaScript.
Criar uma aplicação interativa que manipula strings (texto) de forma simples.
Desenvolver uma interface amigável e funcional para o usuário.

🌐 Tecnologias Utilizadas
HTML: Estruturação do conteúdo.
CSS: Estilização da interface, tornando-a mais agradável visualmente.
JavaScript: Lógica de codificação e decodificação das palavras.

🎯 Funcionalidades
Inserir uma palavra ou frase para codificação.
Gerar uma versão codificada da palavra ou frase.
Inserir uma palavra ou frase codificada para decodificação.
Reverter o texto codificado ao seu estado original.
